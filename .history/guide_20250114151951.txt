
# GUIDE.txt

## 개요

Prompt Collaboration Platform에 오신 것을 환영합니다! 이 서비스는 프롬프트 기반 워크플로우를 생성, 수정 및 협업할 수 있는 플랫폼으로, 실시간 동기화 및 종합적인 보고 기능을 제공합니다.

---

## 주요 기능

1. **프롬프트 처리**
   - 자연어 프롬프트를 입력하여 SQL 쿼리를 생성하거나 인사이트를 도출합니다.
   - Langflow와 VectorDB를 결합한 하이브리드 처리를 지원합니다.

2. **실시간 협업**
   - WebSocket 기반 실시간 동기화를 통해 워크플로우 변경 사항을 즉시 반영합니다.

3. **워크플로우 관리**
   - Langflow GUI를 사용하여 워크플로우를 생성 및 수정합니다.
   - 워크플로우 버전 관리 및 실행 기록을 추적합니다.

4. **보고 및 시각화**
   - 다양한 데이터 차원과 지표를 사용하여 보고서를 생성하고 사용자 지정합니다.
   - Streamlit 대시보드와 Grafana를 통해 결과를 시각화합니다.

## 플랫폼 사용 방법

### 1. **프로젝트 등록**
- **Streamlit**:
  1. "Dashboard" 섹션으로 이동합니다.
  2. 프롬프트를 입력하거나 JSON 파일을 업로드하여 워크플로우를 생성합니다.
  3. 워크플로우를 저장하고 실행합니다.

- **Langflow GUI**:
  1. Langflow GUI를 엽니다.
  2. 시각적 인터페이스를 사용하여 워크플로우를 설계합니다.
  3. 워크플로우를 저장하여 협업 및 실행에 활용합니다.

### 2. **워크플로우 수정**
- Streamlit의 "Workflows" 섹션에서 기존 워크플로우를 엽니다.
- Langflow GUI 또는 JSON 에디터를 사용하여 수정합니다.
- 변경 사항을 저장하여 업데이트를 반영합니다.

### 3. **리포트 생성**
- Streamlit의 "Report Selector"에서 리포트 유형을 선택합니다 (예: `source_report`, `page_report`).
- JSON 형식으로 차원, 지표, 필터를 지정합니다.
- "Generate Report" 버튼을 클릭하여 결과를 확인합니다.

### 4. **실시간 협업**
- WebSocket을 사용하여 워크플로우 및 리포트 변경 사항이 모든 사용자에게 즉시 반영됩니다.

## 통합된 툴 및 활용법

### **1. Langflow**
- **역할**: 워크플로우 설계 및 실행.
- **활용법**:
  - Langflow GUI에서 Drag & Drop 방식으로 워크플로우를 설계합니다.
  - 설계한 워크플로우를 JSON 파일로 저장하거나 FastAPI를 통해 실행합니다.
  - Langflow의 결과를 Streamlit UI와 Grafana 대시보드에서 확인합니다.

### **2. VectorDB**
- **역할**: 벡터 유사도 검색을 통해 프롬프트와 관련된 데이터를 검색.
- **활용법**:
  - 프롬프트를 벡터화하여 기존 데이터와의 유사도를 계산합니다.
  - Langflow 워크플로우와 통합하여 추가적인 검색 결과를 제공합니다.

### **3. Grafana**
- **역할**: 시스템 모니터링 및 워크플로우 성능 시각화.
- **활용법**:
  - Prometheus에서 수집된 메트릭 데이터를 Grafana 대시보드에서 확인합니다.
  - Langflow 및 VectorDB 관련 메트릭을 추적합니다 (예: 실행 시간, 결과 수).

### **4. Streamlit**
- **역할**: 사용자 인터페이스 제공.
- **활용법**:
  - 프롬프트 입력, 리포트 생성, 워크플로우 관리 등 사용자 상호작용을 처리합니다.

---

## 각 프론트엔드 페이지 사용법

1. **Dashboard**:
   - 프롬프트를 입력하여 SQL 쿼리를 생성하고 실행 결과를 확인합니다.
   - Langflow 및 VectorDB 결과를 병합하여 시각화합니다.

2. **Rule Manager**:
   - 룰을 추가, 수정, 삭제하여 프롬프트와 SQL 쿼리 매핑을 관리합니다.

3. **Schema Manager**:
   - 데이터베이스 테이블의 스키마를 관리하고 수정합니다.

4. **Report Selector**:
   - 차원과 지표를 기반으로 리포트를 생성하고 결과를 시각화합니다.

5. **Workflows**:
   - Langflow에서 정의된 워크플로우를 실행하거나 새 워크플로우를 생성합니다.

6. **History**:
   - 이전 워크플로우 실행 기록과 결과를 확인합니다.

---

## 데이터베이스 관리 및 프롬프트 구조

### 데이터베이스 삽입 및 형식
- 데이터는 `init_db.py`를 통해 초기화되며, JSON 스키마로 정의됩니다.
- **예시**:
  ```python
  TableSchema(
      table_name="source_report",
      schema={
          "event_date": "STRING",
          "source_medium": "STRING",
          "regular_donation": "INT64",
          "temporary_donation": "INT64"
      }
  )
  ```

### 프롬프트 구조 및 활용
- **구조**:
  ```json
  {
      "prompt": "2024년 12월 정기후원 총액을 알려줘.",
      "dimensions": ["event_date"],
      "metrics": ["regular_donation"]
  }
  ```
- **활용**:
  - Streamlit 또는 FastAPI를 통해 입력된 프롬프트를 Langflow 워크플로우로 전달.
  - SQL 쿼리를 생성하고 실행하여 결과 반환.

## 문제 해결

1. **Streamlit 대시보드가 로드되지 않을 때**:
   - `streamlit run frontend/app.py` 명령어를 실행 중인지 확인.

2. **Langflow GUI에 접근할 수 없을 때**:
   - Langflow 서버가 실행 중인지 확인: `http://localhost:7860`.

3. **리포트 생성 오류**:
   - 차원, 지표, 필터 입력 형식을 검토.
   - `prompt_rules.json`에서 유효한 옵션 확인.

```bash
python init_db.py
```

**결과**:
- 데이터베이스(`test.db`) 생성.

### **2. 주요 기능 명세 및 활용**

---

#### **2.1 프롬프트 입력 및 데이터 탐색**

##### **사용 흐름**:
1. **프롬프트 입력**:
   - 사용자 프롬프트를 FastAPI의 `/process-prompt` API에 POST 요청.
2. **조건 파싱**:
   - 프롬프트에서 날짜, 소스/매체 등 조건을 추출.
3. **SQL 생성**:
   - 조건에 따라 SQL 쿼리를 생성.
4. **데이터 실행 및 반환**:
   - SQL을 실행하고 결과를 반환.

##### **사용 예시**:

###### **프롬프트 예시**:
"2024년 12월 정기후원 총액을 알려줘."

**API 호출**:
```http
POST /process-prompt
Content-Type: application/json
{
    "prompt": "2024년 12월 정기후원 총액을 알려줘."
}
```

**응답**:
```json
{
    "sql_query": "SELECT SUM(regular_donation) AS total_regular FROM source_report WHERE event_date LIKE '2024-12%';",
    "query_result": [
        {"total_regular": 50000}
    ]
}
```

---

#### **2.2 룰 관리**

##### **사용 흐름**:
1. **룰 추가 또는 수정**:
   - FastAPI의 `/rules` API 또는 Streamlit UI를 통해 룰 관리.
2. **룰 실시간 업데이트**:
   - WebSocket을 통해 룰이 수정되었을 때 모든 클라이언트에 알림.

##### **사용 예시**:

###### **Streamlit 룰 관리**:
1. Streamlit 실행:
   ```bash
   streamlit run frontend/rule_manager_ui.py
   ```
2. 브라우저에서 룰 관리 페이지 접근.
3. 룰 ID, 키워드, 테이블, 측정기준, 측정항목 등을 입력하고 저장.

###### **FastAPI 룰 API**:
```http
PUT /rules/{rule_id}
Content-Type: application/json
{
    "keywords": ["정기후원", "일시후원"],
    "table": "source_report",
    "dimensions": ["event_date"],
    "metrics": ["regular_donation", "temporary_donation"]
}
```

---

#### **2.3 테이블 스키마 관리**

##### **사용 흐름**:
1. **스키마 추가 또는 수정**:
   - Streamlit UI를 통해 테이블 스키마를 관리.
2. **스키마 활용**:
   - SQL 생성 시 참조하여 테이블의 필드와 타입을 검증.

##### **사용 예시**:

###### **Streamlit 스키마 관리**:
1. Streamlit 실행:
   ```bash
   streamlit run frontend/schema_manager.py
   ```
2. 브라우저에서 테이블 이름과 스키마(JSON 형식)를 입력하고 저장.

###### **FastAPI 스키마 API**:
```http
POST /table-schema
Content-Type: application/json
{
    "table_name": "source_report",
    "schema": {
        "event_date": "STRING",
        "source_medium": "STRING",
        "regular_donation": "INT64",
        "temporary_donation": "INT64"
    }
}
```

---

#### **2.4 리포트 데이터 추출**

##### **사용 흐름**:
1. **리포트 유형 선택**:
   - Streamlit UI 또는 `/report-data` API를 사용.
2. **조건 설정 및 데이터 추출**:
   - 조건에 따라 데이터를 필터링하여 SQL 생성 후 실행.

##### **사용 예시**:

###### **리포트 생성**:
```http
POST /report-data
Content-Type: application/json
{
    "report_type": "source_report",
    "dimensions": ["source_medium"],
    "metrics": ["regular_donation"],
    "filters": {"event_date": "2024-12"}
}
```

**응답**:
```json
{
    "sql_query": "SELECT source_medium, SUM(regular_donation) AS total_regular FROM source_report WHERE event_date LIKE '2024-12%' GROUP BY source_medium;",
    "query_result": [
        {"source_medium": "google", "total_regular": 10000},
        {"source_medium": "facebook", "total_regular": 8000}
    ]
}
```

#### **2.5 LangFlow 워크플로우 활용**

##### **사용 흐름**:

2. **워크플로우 실행**:

```http
}
```
