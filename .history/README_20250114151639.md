
## Overview

This repository contains a highly modular and scalable codebase designed for managing prompt-based workflows, real-time collaboration, and data visualization. The project integrates **Langflow**, **VectorDB**, **Streamlit**, and **Grafana** to provide a robust platform for prompt handling, workflow execution, and system monitoring.

---

## Key Features

- **Prompt Handling**: Process prompts using Langflow, VectorDB, or a hybrid mode.
- **Real-Time Collaboration**: WebSocket integration ensures real-time synchronization of workflows.
- **Database Support**: Supports SQLite and PostgreSQL for flexible database management.
- **System Monitoring**: Grafana dashboards provide insights into workflow execution and query performance.
- **Modular Design**: Easily extend or modify individual components.

---

## Getting Started

### Prerequisites
- **Docker**: Install Docker and Docker Compose.
- **Python**: Ensure Python 3.9+ is installed locally if running without Docker.

---

### Setup and Execution

#### **1. Using Docker**

1. Build and run the Docker containers:
   ```bash
   docker-compose up --build
   ```
2. Access the services:
   - Streamlit App: [http://localhost:8501](http://localhost:8501)
   - Langflow GUI: [http://localhost:7860](http://localhost:7860)
   - Grafana Dashboard: [http://localhost:3000](http://localhost:3000)

#### **2. Manual Setup**

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Initialize the database:
   ```bash
   python init_db.py
   ```
3. Run the FastAPI server:
   ```bash
   uvicorn app.main:app --host 0.0.0.0 --port 8000
   ```
4. Run the Streamlit app:
   ```bash
   streamlit run frontend/app.py
   ```

---

### Environment Variables

| Variable                | Default Value                          | Description                         |
|-------------------------|----------------------------------------|-------------------------------------|
| `DATABASE_TYPE`         | `sqlite`                              | Database type (`sqlite` or `postgresql`)
| `DATABASE_URL`          | `sqlite:///./test.db`                 | Database connection URL             |
| `PROMETHEUS_PUSHGATEWAY`| `http://localhost:9091`               | Prometheus PushGateway URL          |
| `LANGFLOW_API_BASE`     | `http://localhost:7860/api/v1`        | Langflow API base URL               |
| `USE_LANGFLOW`          | `true`                                | Enable Langflow                     |
| `USE_VECTORDB`          | `true`                                | Enable VectorDB                     |
