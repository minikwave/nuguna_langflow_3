# Prompt Collaboration Platform

## Overview

The **Prompt Collaboration Platform** provides an integrated solution for processing natural language prompts to generate and execute SQL queries, enabling dynamic data exploration and reporting. This platform supports:
1. **Condition-Based Querying**: SQL generation based on user-defined conditions.
2. **Report Extraction**: Generate detailed reports for multiple data types (e.g., source reports, page reports).
3. **Real-Time Collaboration**: WebSocket-based real-time updates for collaborative rule management.
4. **Integration with LangFlow**: Flexible workflows for custom query execution.
5. **Metrics Monitoring**: Performance tracking via Prometheus and Grafana.

---

## Features

- **Dynamic SQL Generation**: Parse conditions from user prompts to generate SQL queries dynamically.
- **Report Management**: Extract data using predefined or custom reports.
- **Rule Management**: Add, edit, and delete rules for condition-based query execution.
- **Schema Management**: Define and manage table schemas dynamically.
- **Real-Time Collaboration**: WebSocket-based notifications for live updates.
- **LangFlow Integration**: Visualize and execute workflows for query and report generation.
- **Performance Monitoring**: Track query execution time and results with Prometheus and Grafana.

## Installation and Setup

### Prerequisites

1. **Python 3.9+**
2. **Docker and Docker Compose**
3. **Prometheus and Grafana** (managed through Docker Compose)

### Environment Variables

Create a `.env` file in the root directory:

```plaintext
DATABASE_URL=sqlite:///./test.db
LANGFLOW_API_KEY=your_langflow_api_key
PROMETHEUS_PUSHGATEWAY=http://localhost:9091
```

### Installation Steps

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-repo/project.git
   cd project
   ```

2. **Install Python dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Initialize the database**:
   ```bash
   python init_db.py
   ```

4. **Run the services with Docker Compose**:
   ```bash
   docker-compose up --build
   ```

5. **Run Streamlit UI**:
   ```bash
   streamlit run frontend/schema_manager.py
   ```

## Usage

### FastAPI Endpoints

Access FastAPI documentation at: [http://localhost:8000/docs](http://localhost:8000/docs)

- **Prompt Processing**:
  ```http
  POST /process-prompt
  Content-Type: application/json
  {
      "prompt": "2024년 12월 정기후원 총액을 알려줘."
  }
  ```

- **Rule Management**:
  ```http
  PUT /rules/{rule_id}
  Content-Type: application/json
  {
      "keywords": ["정기후원", "일시후원"],
      "table": "source_report",
      "dimensions": ["event_date"],
      "metrics": ["regular_donation", "temporary_donation"]
  }
  ```

### Streamlit UI

1. **Schema Management**:
   ```bash
   streamlit run frontend/schema_manager.py
   ```

2. **Rule Management**:
   ```bash
   streamlit run frontend/rule_manager_ui.py
   ```

3. **Report Selection**:
   ```bash
   streamlit run frontend/report_selector.py
   ```
