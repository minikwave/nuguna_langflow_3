### **사용 설명서: 사용자 중심 플로우에 따른 Prompt Collaboration Platform 가이드**

---

### **1. 세팅 및 설치**

#### **1.1 프로젝트 세팅**

##### **1) 프로젝트 클론**
GitHub에서 프로젝트를 클론:
```bash
git clone https://github.com/your-repo/project.git
cd project
```

##### **2) Python 패키지 설치**
`requirements.txt`를 사용하여 의존성 설치:
```bash
pip install -r requirements.txt
```

##### **3) 환경 변수 설정**
루트 디렉토리에 `.env` 파일 생성:
```plaintext
DATABASE_URL=sqlite:///./test.db
LANGFLOW_API_KEY=your_langflow_api_key
PROMETHEUS_PUSHGATEWAY=http://localhost:9091
```

##### **4) 데이터베이스 초기화**
`init_db.py`를 실행하여 SQLite 데이터베이스를 초기화:
```bash
python init_db.py
```

**결과**:
- 데이터베이스(`test.db`) 생성.
- 테이블 스키마, 룰, 워크플로우 등의 초기 데이터가 삽입됨.

---

#### **1.2 서버 실행**

##### **1) FastAPI 서버 실행**
FastAPI 서버를 실행하여 API와 LangFlow 워크플로우를 활성화:
```bash
uvicorn app.main:app --reload
```

**URL**: [http://localhost:8000/docs](http://localhost:8000/docs)

##### **2) Streamlit UI 실행**
사용자 인터페이스를 실행:
```bash
streamlit run frontend/schema_manager.py
```

**URL**: [http://localhost:8501](http://localhost:8501)

##### **3) Docker Compose 실행**
Prometheus와 Grafana를 실행하여 성능 및 메트릭을 모니터링:
```bash
docker-compose up --build
```

**Grafana URL**: [http://localhost:3000](http://localhost:3000)

---

### **2. 주요 기능 명세 및 활용**

---

#### **2.1 프롬프트 입력 및 데이터 탐색**

##### **사용 흐름**:
1. **프롬프트 입력**:
   - 사용자 프롬프트를 FastAPI의 `/process-prompt` API에 POST 요청.
2. **조건 파싱**:
   - 프롬프트에서 날짜, 소스/매체 등 조건을 추출.
3. **SQL 생성**:
   - 조건에 따라 SQL 쿼리를 생성.
4. **데이터 실행 및 반환**:
   - SQL을 실행하고 결과를 반환.

##### **사용 예시**:

###### **프롬프트 예시**:
"2024년 12월 정기후원 총액을 알려줘."

**API 호출**:
```http
POST /process-prompt
Content-Type: application/json
{
    "prompt": "2024년 12월 정기후원 총액을 알려줘."
}
```

**응답**:
```json
{
    "sql_query": "SELECT SUM(regular_donation) AS total_regular FROM source_report WHERE event_date LIKE '2024-12%';",
    "query_result": [
        {"total_regular": 50000}
    ]
}
```

---

#### **2.2 룰 관리**

##### **사용 흐름**:
1. **룰 추가 또는 수정**:
   - FastAPI의 `/rules` API 또는 Streamlit UI를 통해 룰 관리.
2. **룰 실시간 업데이트**:
   - WebSocket을 통해 룰이 수정되었을 때 모든 클라이언트에 알림.

##### **사용 예시**:

###### **Streamlit 룰 관리**:
1. Streamlit 실행:
   ```bash
   streamlit run frontend/rule_manager_ui.py
   ```
2. 브라우저에서 룰 관리 페이지 접근.
3. 룰 ID, 키워드, 테이블, 측정기준, 측정항목 등을 입력하고 저장.

###### **FastAPI 룰 API**:
```http
PUT /rules/{rule_id}
Content-Type: application/json
{
    "keywords": ["정기후원", "일시후원"],
    "table": "source_report",
    "dimensions": ["event_date"],
    "metrics": ["regular_donation", "temporary_donation"]
}
```

---

#### **2.3 테이블 스키마 관리**

##### **사용 흐름**:
1. **스키마 추가 또는 수정**:
   - Streamlit UI를 통해 테이블 스키마를 관리.
2. **스키마 활용**:
   - SQL 생성 시 참조하여 테이블의 필드와 타입을 검증.

##### **사용 예시**:

###### **Streamlit 스키마 관리**:
1. Streamlit 실행:
   ```bash
   streamlit run frontend/schema_manager.py
   ```
2. 브라우저에서 테이블 이름과 스키마(JSON 형식)를 입력하고 저장.

###### **FastAPI 스키마 API**:
```http
POST /table-schema
Content-Type: application/json
{
    "table_name": "source_report",
    "schema": {
        "event_date": "STRING",
        "source_medium": "STRING",
        "regular_donation": "INT64",
        "temporary_donation": "INT64"
    }
}
```

---

#### **2.4 리포트 데이터 추출**

##### **사용 흐름**:
1. **리포트 유형 선택**:
   - Streamlit UI 또는 `/report-data` API를 사용.
2. **조건 설정 및 데이터 추출**:
   - 조건에 따라 데이터를 필터링하여 SQL 생성 후 실행.

##### **사용 예시**:

###### **리포트 생성**:
```http
POST /report-data
Content-Type: application/json
{
    "report_type": "source_report",
    "dimensions": ["source_medium"],
    "metrics": ["regular_donation"],
    "filters": {"event_date": "2024-12"}
}
```

**응답**:
```json
{
    "sql_query": "SELECT source_medium, SUM(regular_donation) AS total_regular FROM source_report WHERE event_date LIKE '2024-12%' GROUP BY source_medium;",
    "query_result": [
        {"source_medium": "google", "total_regular": 10000},
        {"source_medium": "facebook", "total_regular": 8000}
    ]
}
```

---

#### **2.5 LangFlow 워크플로우 활용**

##### **사용 흐름**:
1. **워크플로우 정의**:
   - LangFlow JSON 파일(`langflow/workflows/`)에 워크플로우 정의.
2. **워크플로우 실행**:
   - FastAPI `/execute-workflow` API를 통해 실행.

##### **사용 예시**:

###### **워크플로우 실행**:
```http
POST /execute-workflow
Content-Type: application/json
{
    "workflow_id": "condition-workflow",
    "inputs": {
        "prompt": "2024년 12월 정기후원 총액을 알려줘."
    }
}
```

##### **사용 흐름**:

###### **WebSocket 알림**:
